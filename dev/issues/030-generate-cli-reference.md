# [feat] Generate the CLI reference

Option lists are hand-written in `lookup.md` and `build.md` and will drift. Generate them from the Click group so the help text is the one source.

Depends on 028. Spec: `dev/specs/structured-documentation.md`

## Acceptance Criteria

- `docs/reference.md` is generated by mkdocs-click from the `harald-cli` group. It covers every command, its options, and `--config`/`HARALD_CONFIG`.
- `mkdocs-click` is added to `docs/requirements.txt` and not to `pyproject.toml`.
- Help-text and docstring wording that the reference surfaces reads as user documentation. No behaviour changes.
- The hand-written pages explain behaviour and no longer list options.
- The build command is `uv run --with-requirements docs/requirements.txt mkdocs build --strict -f docs/mkdocs.yml`. CI and the README instructions use it, and the `pip install` instructions go.
- The page is in the nav, and the strict build passes.
