| Source | Licence | Attribution |

| Tatoeba | CC BY 2.0 FR | Tatoeba contributors (tatoeba.org) |

`harald-cli info` prints these along with each source's date.

The built `lexicon.db` is derived from share-alike data and is **never
redistributed**; it is built locally and moved only between your own devices.

## Coverage

The data is as complete as Wiktionary. `harald-cli info` reports, for
information only, how many verbs have complete Stammformen, how many nouns
have a gender and how many senses have a translated example.
